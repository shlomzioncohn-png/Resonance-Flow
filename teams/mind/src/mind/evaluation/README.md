# evaluation

Evaluation harness + metrics.

- Scores a ranking model against `eval/personas/` — a fixed scenario set, never touched mid-comparison.
- Must be runnable by someone outside the MIND team (Foundation Gate requirement).
- Metric choice (top-1 accuracy vs. MRR/nDCG) — open decision, close with mentor in week 1.
- Used for both the baseline (week 6) and the stretch-goal comparison (week 7, demo day week 9).
